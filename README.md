## 📋 Menu de Funcionalidades | Features
> **Focada na gestão de arquivos de mundo e otimização de performance.**

### 🔄 CHUNKS
* **PT:** Limpeza seletiva de Spawn (0.0) e Bases (0.1) para regeneração.
* **EN:** Selective cleaning of Spawn (0.0) and Bases (0.1) for regeneration.

### 📦 BACKUP
* **PT:** Restauração rápida via arquivos `.ZIP`.
* **EN:** Fast restoration via `.ZIP` files.

### ⚡ OTIMIZAÇÃO / OPTIMIZATION
* **PT:** Versão 1.2 ultra leve, focada no que o jogo não faz nativamente.
* **EN:** Ultra-light version 1.2, focusing on what the game doesn't do natively.
